## 三、IsolationScope 四种模式：`{ns}` 前缀的插入规则



依据 \[IsolationScope\.java L102\-126\]\(file:///C:/workspace/opensources/agentscope\-java\-2\.0/agentscope\-harness/src/main/java/io/agentscope/harness/agent/IsolationScope\.java\#L102\-L126\)，`{ns}` 由 \[WorkspaceManager\.resolveRuntimeDataPath L239\-248\]\(file:///C:/workspace/opensources/agentscope\-java\-2\.0/agentscope\-harness/src/main/java/io/agentscope/harness/agent/workspace/WorkspaceManager\.java\#L239\-L248\) 插入到**所有经 filesystem 层的读写路径**前：



```Plain Text
workspace.resolve(String.join("/", ns)).resolve(relativePath)
```



|IsolationScope|namespace|MEMORY\.md 实际路径|每日流水账实际路径|共享范围|
|---|---|---|---|---|
|**USER**（默认）|`[userId]`|`workspace/<userId>/MEMORY.md`|`workspace/<userId>/memory/YYYY-MM-DD.md`|同用户所有会话|
|**USER**（uid 缺失回退）|`[sessionId]`|`workspace/<sessionId>/MEMORY.md`|`workspace/<sessionId>/memory/...`|退化为单会话|
|**SESSION**|`[sessionId]`|`workspace/<sessionId>/MEMORY.md`|`workspace/<sessionId>/memory/...`|每会话独立|
|**AGENT**|`[]`（无前缀）|`workspace/MEMORY.md`|`workspace/memory/...`|同一 agent 所有用户共享|
|**GLOBAL**|`[]`（无前缀）|`workspace/MEMORY.md`|`workspace/memory/...`|同一 workspace/store 全局共享|
|无 filesystem（纯本地退化）|不适用|`workspace/MEMORY.md`|`workspace/memory/...`|workspace 级共享（不按用户隔离）|



> 注意：`AGENTS.md`、`MEMORY.md`、`memory/`、`agents/<agentId>/sessions|tasks` 等运行时数据路径都带 `{ns}`；而 `skills/`、`knowledge/`、`rules/`、`subagents/`、`tools.json` 等智能体资产是 workspace 级共享。

## 四、子智能体的三种 workspace 模式



依据 \[HarnessAgentBuilderSupport\.resolveDeclaredWorkspace L709\-732\]\(file:///C:/workspace/opensources/agentscope\-java\-2\.0/agentscope\-harness/src/main/java/io/agentscope/harness/agent/HarnessAgentBuilderSupport\.java\#L709\-L732\)：



### 模式 1：ISOLATED（默认）— 独立递归结构



子智能体有**完整独立的运行时根**，且继承父的 `memoryConfig`（记忆钩子默认启用），记忆写入**自己的目录树**：



```Plain Text

├── MEMORY.md                                   # 主智能体用户总账
├── memory/                                     # 主智能体用户流水账
│   └── 2026-10-08.md
│
└── agents/
    ├── <主智能体id>/
    │   ├── sessions/...                        # 主智能体会话
    │   └── tasks/...
    │
    └── <子智能体名>/                            # decl.getName()
        ├── sessions/...                        # ← 注意：直接在 agents/<name>/ 下
        ├── tasks/...
        └── workspace/                          # ← ISOLATED 子智能体独立根
            │
            │   # ===== 以下结构与主 workspace 完全同构（递归）=====
            ├── AGENTS.md                       # 子智能体人格
            ├── MEMORY.md                       # 子智能体自己的总账
            ├── memory/                         # 子智能体自己的流水账
            │   ├── 2026-10-08.md
            │   ├── .consolidation_state        # 自己的合并水位线
            │   └── archive/
            ├── skills/
            ├── knowledge/
            ├── plans/
            │
            └── agents/                         # 子智能体作为 leaf subagent，
                └── <子智能体id>/               #   .asLeafSubagent() 不再嵌套子智能体，
                    ├── sessions/...            #   此层只有自己的 sessions/tasks
                    └── tasks/...
```

## 六、关键写入者权限矩阵



|路径|唯一写入者|写入时机|
|---|---|---|
|`memory/YYYY-MM-DD.md`|`MemoryFlushManager` / `MemorySaveTool`|每次调用后（flush）或 Agent 主动保存|
|`MEMORY.md`|`MemoryConsolidator` / `MemorySaveTool`|定期合并（≥30 分钟）或 Agent 主动保存|
|`memory/.consolidation_state`|`MemoryConsolidator`|每次成功合并后|
|`memory/archive/*`|`MemoryMaintenanceMiddleware`|每日文件 \>90 天时|
|`agents/<id>/sessions/*`|`TranscriptMiddleware` / `SessionTranscriptWriter`|每轮对话边界|
|`agents/<id>/tasks/*`|`WorkspaceTaskRepository`|异步任务生命周期|



**核心规则**：流水账追加只写（Layer 1），总账整体覆写（Layer 2），两者由不同组件独占维护，通过 watermark 实现增量合并。
